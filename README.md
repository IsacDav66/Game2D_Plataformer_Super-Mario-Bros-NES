
# Resumen del Proyecto: Juego de Plataformas 2D Estilo Retro "Super Mario Bros."

Este proyecto es una implementación de un juego de plataformas 2D, inspirado en el clásico "Super Mario Bros." de la NES. El juego fue desarrollado utilizando el motor de videojuegos Godot. El objetivo principal del proyecto es recrear la mecánica de juego y la estética del juego original, adaptándolos a una versión moderna y personalizable.

**Características Principales:**

1.  **Mecánica de Juego de Plataformas:**
    *   **Movimiento del Personaje:** El jugador controla un personaje que puede moverse hacia la izquierda o derecha, saltar y realizar acciones básicas.
    *   **Interacción con el Entorno:** El personaje puede interactuar con bloques, monedas, enemigos y otros elementos del escenario.
    *   **Recolección de Monedas:** El jugador puede recolectar monedas a lo largo del nivel para obtener una puntuación.
    *   **Eliminación de Enemigos:** El jugador puede eliminar enemigos saltando sobre ellos o utilizando objetos especiales.

2.  **Diseño de Niveles:**
    *   **Escenarios de Plataformas:** El juego incluye escenarios diseñados con una variedad de plataformas, obstáculos y desafíos.
    *   **Elementos Clásicos:** Se incluyen elementos típicos del juego original como bloques de ladrillo, tubos, montañas y banderas de final de nivel.
    *   **Disposición de Enemigos:** Los enemigos, como los Goombas, están estratégicamente colocados en el nivel para desafiar al jugador.
   
3.  **Interfaz de Usuario (HUD):**
    *   **Puntuación:** La interfaz muestra la puntuación actual del jugador, incluyendo el número de monedas recolectadas.
    *   **Nivel:** Se indica el nivel actual en el que se encuentra el jugador.
    *  **Vidas o HP:** El juego muestra la cantidad de vidas o HP que el jugador posee.
    *   **Menú de Inicio:** Se muestra un menú de inicio con el logo del juego.

4.  **Elementos de Jugabilidad:**
    *   **Bloques con Interrogaciones:** El jugador puede golpear bloques con interrogaciones para obtener objetos especiales o monedas.
    *   **Tubos de Transporte:** El jugador puede entrar en tubos para acceder a diferentes áreas del nivel.
    *   **Bandera de Final de Nivel:** Al llegar a la bandera al final del nivel, se completa el mismo y se avanza al siguiente.

**Tecnologías Utilizadas:**

*   **Godot Engine:** Motor de videojuegos 2D para desarrollar el juego.

**Propósito:**

El juego tiene como objetivo recrear la experiencia de juego de "Super Mario Bros.", ofreciendo un juego de plataformas simple pero entretenido. Además, sirve como un proyecto educativo para aprender a utilizar un motor de videojuegos como Godot, para aplicar conceptos de programación y diseño de juegos.

**Para un Trabajo:**  

Este proyecto es un buen ejemplo de cómo se puede hacer un videojuego básico, implementando elementos básicos de un juego de plataformas. Es ideal para principiantes que buscan aprender y demostrar sus habilidades en el desarrollo de videojuegos.
